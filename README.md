# 走进照片 · 源码交接版

普通用户上传照片，由 AI 推荐体验，确认后生成浏览器内容。场景类希望能前进、绕行、回头；主体类希望通过鼠标或点击获得局部回应。

当前为未完成的实验原型：上传、任务保存、本地模型适配与 GLB 管线已有实现，核心几何和动作效果尚未通过验收。
