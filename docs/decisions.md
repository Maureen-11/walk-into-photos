| 项目 | 决策 |
| --- | --- |
| 目标用户 | 普通空间内容创作者，不限定为校园或个人记忆场景 |
| 首批输入 | 横向走廊或房间照片 |
| 用户输入 | 只上传照片，不输入愿望或提示词 |
| AI 交互 | AI 给出一套方案，用户确认或更换照片 |
| 生成重点 | 先保证与原图相似，再扩大可移动范围 |
| 输出 | 浏览器分享链接 + GLB 下载 |
| 体验 | WASD/方向键移动，鼠标转视角，有限安全范围 |

| 设备 | 用户 RTX 4050 约 6GB 显存的电脑 |
| 主模型 | MoGe-2 Small |
| 备用模型 | Depth Anything V2 Small |
| SHARP | 仅后续许可证审查和对比，不作为当前正式依赖 |
