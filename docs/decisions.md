# 已确认决策

| 项目 | 决策 |
| --- | --- |
| 目标用户 | 普通空间内容创作者，不限定为校园或个人记忆场景 |
| 首批输入 | 八类常见照片；无法准确分类时进入通用分层实验模式 |

| 体验 | WASD/方向键移动，鼠标转视角，有限安全范围 |
| 生成声明 | 遮挡和不可见区域为 AI 估计补全，不是真实重建 |
| 设备 | 用户 RTX 4050 约 6GB 显存的电脑 |
| 规划模型 | 本地 Moondream 2B（首次官方下载后断网运行） |
