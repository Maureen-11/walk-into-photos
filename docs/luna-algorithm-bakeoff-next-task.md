# Luna 下一项小任务：分层网格与断边对照

这是 R1/R2 之后的独立实验任务，不是一次性重写主引擎。

## 目标

验证当前雪山和一张走廊照片是否能通过“深度不连续断边 + 前中后景分层 + 小范围遮挡补全”减少拉丝和钻入灰面。若不能同时保持首帧投影和有限前进，就停止该路线，转为选型结论，不把它接入生产。

## Luna 执行协议

- **允许修改**：只允许新增 `backend/scripts/bakeoff/` 实验脚本、`docs/reports/` 记录和 D 盘实验输出。
- **禁止修改**：`backend/app/services/geometry.py`、主API、前端控制器、数据库、已有场景、第三方源码和系统CUDA。
- **输入**：R1同一雪山样片 + 一张走廊样片；固定当前MoGe输出、相机内参和起点。
- **输出**：每张图至少三份GLB：`surface_only`、`depth_disconnected`、`layered_inpaint_candidate`；每份附 `manifest.json`、覆盖率、边长/面质量、相机和测试范围。
- **方法限制**：
  1. 先依据相邻像素深度比和图像边界断开跨越明显不连续处的三角面；不要用单一全局20倍阈值。
  2. 分层补全只覆盖小视差范围；不可见区域必须在manifest标记为AI候选，不得伪称真实空间。
  3. 实验中关闭程序化上下文壳层，先看几何本身；壳层只能作为另一个对照变量。
  4. 若引入3D Photo Inpainting代码，先记录MIT许可和旧依赖，不自动安装生产环境。
- **验收命令**：脚本 `--help`；同一输入生成三份GLB；读取manifest；质量检查；后端现有测试 `python -m pytest -q`。
- **视觉验收**：首帧、前进、侧移、上升、下降、回头各一张；至少两种照片；不能用灰地面或天空球遮住洞后宣布通过；需要明确测试最大安全移动距离。
- **失败回退**：任何OOM、依赖失败或首帧变差都只保留实验产物并记录，不改生产；若分层补全只在小视差有效，标记 `passed_limited_view`，不能写 `passed_navigation`。
- **完成汇报**：报告实际命令、输入hash、代码commit、产物路径、耗时、峰值显存、三种版本的质量差异、视觉证据和是否建议进入R3。

## 通过门

只有在雪山和走廊均满足“首帧保真 + 有限前进不出现大面积拉丝/灰面 + 回头仍可解释”时，才允许继续做独立查看器适配；否则结束算法对比并给出“当前硬件下不应重写为完整自由漫游”的结论。

## 当前执行结果补充

已完成的“只断边”和“三层深度”最低成本对照均未通过：雪山候选的自动长宽比P99反而上升，且没有补出不可见空间。因此本任务不得继续调分层阈值。下一次若继续，只能接入一个真正的遮挡颜色/深度补全实现（优先隔离验证3D Photo Inpainting思路）；若依赖或硬件不满足，则直接进入R4决策，不再重写一个未经验证的全场景引擎。
