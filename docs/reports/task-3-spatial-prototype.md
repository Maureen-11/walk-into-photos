# 任务 3：有限空间可探索试验

执行日期：2026-09-13
状态：部分完成，待浏览器路线验收。

## 已验证

- 本地断网环境下，Moondream 对雪山、俯拍街道、笼中猫样片均返回了具体类别；雪山为 `natural_landscape`，街道为 `street_city`，猫为 `animal_closeup`。
- MoGe v2 在本机 RTX 4050 Laptop（6141 MiB）上为雪山、街道、猫图生成了真实 GLB；已观察到单张结果约 12.4MB（雪山）、18.1MB（街道）、16.6MB（猫图）。
- `coverage` 现在在没有 mask 输出时返回 `null`；不再用固定 0.9 作为覆盖率。
- 移动协议新增地面跟随、起点重置、碰撞半径和路线检查点字段；前端加入 `R` 回到起点，并在完整版资源替换时保留相机位置。

## 尚未通过

GLB 生成成功不等于“能走进去”。当前尚未完成真实浏览器录屏来证明：

1. 雪山从拍摄点沿雪地前进，经过连续高低地形后回头仍看见稳定远景；
2. 室内能绕开真实障碍而不是穿过单面网格；
3. 俯拍街道下降后仍保持合理的地面和视角；
4. 退出／切换版本时不跳到无关坐标。

当前前端仍主要依赖 manifest 边界限幅；没有从照片网格建立经过验证的碰撞体，不能把 `collision_radius` 字段称为已实现碰撞。随机粒子效果已移除，避免用装饰性动画冒充场景补全。
