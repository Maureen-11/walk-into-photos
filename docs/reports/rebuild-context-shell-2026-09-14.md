# 上下文壳层实验记录（2026-09-14）

## 目的

T04 走廊和 T05 雪山的首轮真实样片在侧向视角出现大面积空黑。为验证“有限探索是否能比黑洞更好”，增加一个可撤回的程序化上下文壳层：不改动原始 MoGe 网格，不扩大用户移动边界，不宣称复原不可见空间。

## 实现

- `backend/app/services/context_shell.py`
  - 室内模板：地面、顶棚、左右墙和远端墙的中性材质盒体。
  - 自然风景模板：浅色雪地、低多边形天空球和少量远景山脊。
- `EXPERIMENTAL_CONTEXT_SHELL=true` 默认开启，但 manifest 明确写入 `experimental_needs_visual_review`。
- 前端加载场景后将材质设为 `THREE.DoubleSide`，避免人在壳层内部看到盒体背面被剔除后的黑洞。
- MoGe 网格在导出前增加保守的深度稳定与极端三角形过滤：沿原相机射线做小范围深度平滑，并删除超过网格中位最长边 20 倍的三角形；删除数量写入 `quality_metrics.geometry_cleanup`。
- 原始移动 AABB保留；壳层只负责视觉上下文，不把天空球或远景山脊变成可走区域。

## 当前结论

代码层面已解决一个明确问题：壳层内侧面的默认背面剔除不会再必然造成黑洞。**但本轮不能判定视觉通过**：当前浏览器截图接口返回“Unable to capture screenshot”，因此没有可交付的侧向画面证据。需要下一次浏览器截图或用户录屏确认：

1. 走廊侧向是否看见连续墙体而不是大块灰色盒子；
2. 雪山侧向和飞行时天空／山脊是否只是背景，不会遮住原始可见网格；
3. 回头、WASD、飞行边界是否仍在合理位置；
4. 是否出现廉价平面、穿模、颜色跳变或明显不符合照片透视的壳层。

如果任一项失败，应把 `EXPERIMENTAL_CONTEXT_SHELL` 改为 `false`，保留本报告作为失败证据，转向分层几何或多视图输入，而不是继续堆叠更大的程序化盒体。
