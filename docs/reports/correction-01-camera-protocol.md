# 修正阶段 1：相机与几何协议

日期：2026-09-14
状态：代码与端到端接口通过；浏览器路线和视觉质量仍未通过最终验收。

## 已完成

- 增加 `CameraSpec`：保存 MoGe `intrinsics`、`image_size`、`camera_to_world`、`world_scale`、`near/far`、水平/垂直 FOV 和坐标系版本。
- MoGe 生成改为调用官方 Python API，保留 mask 和内参；不再依赖 Windows OpenCV 不支持的 EXR 输出。
- GLB 只做绕 `[0,0,0]` 相机原点的统一缩放，不做 x/y/z 非等比拉伸、不做任意平移和居中。
- 前端删除 GLB 的隐式 `scale={1.1}` 和 real 场景固定 `68°` FOV；离线查看器也读取 manifest 的相机字段。
- real 场景首次相机起点为 MoGe 相机原点；在地面、碰撞和路线验收完成前，暂时关闭旧模板的 `ground_follow`，避免自动把相机推到虚构地面。
- mask 覆盖率现在是质量证据而不是普通照片的硬拒绝条件；低覆盖率场景会保留并标成 `unverified`。
