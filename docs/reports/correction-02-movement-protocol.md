# 修正阶段 2：观察者尺度与移动协议

日期：2026-09-14
状态：控制器代码与接口测试通过；地面、家具/山体碰撞和路线录屏仍未通过视觉验收。

## 本阶段改动

- real manifest 的运动边界从统一缩放后的场景 AABB 推导，并包含相机原点；不再把所有真实场景强行塞进一套固定范围。
- 在地面/碰撞代理完成前，真实场景关闭旧模板的常量 `ground_follow`，防止相机被硬推到虚构的 `y=0.1/1.55`。
- 前进和侧移按向量归一化，斜向不再比直行快；长帧最大按 50ms 计算，避免窗口卡顿时瞬移穿过薄面。
- 窗口失焦和页面隐藏会清空按键集合，避免 W/F 等键状态残留。
- `?debug=1` 时显示位置、FOV 和统一缩放；普通模式不显示工程字段。

## 当前边界

这是“可控、可回退”的 AABB 观察范围，不是语义碰撞。它暂时不能证明能绕过沙发、沿雪地贴地或从街道高处安全下降；这些需要后续按场景引擎建立地面/障碍代理并录像验证。
