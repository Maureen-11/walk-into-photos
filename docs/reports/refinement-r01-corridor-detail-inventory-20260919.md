# R01 走廊精细化清单：I01

这份清单是 R02/R03 的输入。每个条目都要在候选场景的近景截图和路线录像中给出结果；“已在 V47 看到”是保留要求，“候选新增”是改善方向，不代表照片中真实存在的不可见结构。

## 走廊主次关系

主结构是长向走廊的消失点、两侧开口节奏、连续地面和尽端窗。次结构是门窗边框、踢脚线、灯具、地面接缝和局部墙面色带。远端细节应逐步简化，近端细节需要有厚度和材质分层。

| 区域 | V47 已有且必须保留 | R02/R03 改善 | 证据观察点 |
|---|---|---|---|
| 左侧开口 | 深色竖向框、玻璃/窗面分块、窗台与水平构件 | 统一窗框厚度，玻璃采用少量明暗变化，减少重复方块的噪声 | 起点左转、靠近第一个窗湾 |
| 右侧开口 | 木色门列、门面分层、横向把手/装饰件、墙面架状细节 | 门扇、门框、把手形成真实前后关系；把零散装饰合并成可读面 | 起点右转、靠近第一个门 |
| 地面 | 走廊方向明确、重复地面块和横向节奏 | 保留地面节奏，降低无意义色块对比；地面与墙脚有接触阴影 | 起点俯视、走到中段 |
| 天花 | 黑/暖色重复灯具序列、纵向透视 | 灯具外框、发光面和天花嵌入关系分层；保持灯距与消失点 | 起点抬头、走廊中线 |
| 墙脚与墙面 | 深色踢脚线、墙面大色带 | 让踢脚线与墙相交，不悬浮；补足墙面转角和开口内衬 | 左右侧移、回头 |
| 尽端 | 尽端窗/图案作为路线终点 | 增加窗内远景层级但不把平面背景当真实空间；确保走近不穿透 | 末端检查点、回头看 |
| 中央家具/长凳 | V47 路线中有尺度锚点 | 保留可绕行间距，增加座面/支撑的结构关系；不让它挡住主路线 | [1.55,1.625,-3] 附近 |

## 材质与颜色要求

- 墙、木门、玻璃、地面、金属灯具必须有独立材质角色；不能只用一个颜色乘不同亮度。
- 颜色从 I01 照片和 V47 已有关系出发；颜色数量没有八色硬上限，但每个观察点应能说出主色、辅色和强调色的作用。
- 细节采用分组色阶，禁止每个小块随机换色。近端可有 3–5 个明暗层级，远端应减少层级。
- 主要光线来自左侧窗面；门窗凹槽、踢脚线、长凳脚和地面接触处必须有可读阴影。若查看器没有实际读取新光照预设，不能在报告中写“已完成光照”。

## 五个固定观察点

1. 起点正视：验证长向透视、灯具序列、左右开口、地面方向。
2. 左窗近景：验证窗框厚度、玻璃层次、窗台连接和墙脚。
3. 右门近景：验证门扇、门框、把手、门口墙面与碰撞。
4. 中段侧后方：从中段向侧面移动，再回头，验证物体背面和墙地连接，不出现空壳、漂浮或突然消失。
5. 尽端回头：走到 z 约为 -7.8 附近回看起点，验证远近层次和路线连续。

## R02/R03 通过条件

- 任意观察点不低于 V47 的可见细节密度；减少对象数量只有在合并后轮廓和信息仍然清楚时才允许。
- 所有 V47 清单中的主要细节均有“保留/改善/退步”结论，不能留空。
- 不出现穿墙、穿门、掉出地面、失焦持续移动或页面滚动。
- 走廊照片特征仍然清楚；如果候选变成通用商场或通用酒店走廊，视为失败。
- 候选先保持 unverified，通过结构和真实离线运行后，交给用户做视觉确认。
