# 项目大纲

## 目标

让普通用户不需要写提示词，也能把一张空间照片转成一个可有限探索的浏览器场景。

## 用户流程

```text
邀请码 → 上传照片 → AI 分析适用性 → 展示唯一推荐方案
      → 用户确认 → 生成几何 → 质量检查 → 有边界地探索 → 分享/下载
```

## 智能体步骤

1. 分析照片：判断场景类型、主体、可见深度线索和风险。
2. 规划移动：从固定体验预设中选择安全的移动范围。
3. 调用工具：调用视觉模型、深度/几何生成器和 GLB 检查器。
4. 处理异常：对不支持照片、模型失败、显存不足和空洞缩小范围或拒绝。
5. 交付结果：给出场景、来源说明、限制条件、分享链接和 GLB。

## 状态机

`UPLOADED → ANALYZED → WAITING_CONFIRMATION → QUEUED → GENERATING → VALIDATING → READY`

异常状态：`REJECTED`、`FAILED`、`EXPIRED`。

## 评分对应

| 赛事关注点 | 项目证据 |
| --- | --- |
| 任务理解与自主规划 | AI 从照片判断适用性并选择体验预设 |
| 工具调用与环境交互 | DeepSeek Vision、MoGe/备用深度模型、GLB 检查器 |
| 结果交付与可验收性 | 可操作场景、分享链接、GLB 下载、测试记录 |
| 真实场景价值 | 普通创作者无需3D建模即可制作空间内容 |
