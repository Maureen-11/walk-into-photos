# 项目大纲

## 目标

让普通用户不需要写提示词，也能把照片转成一个可移动、可环顾的浏览器场景。照片不可见区域始终标注为 AI 估计或程序化创作。

## 用户流程

```text
拖入/选择照片 → 本地视觉分析 → 推荐模板与理由
      → 用户选择兼容模板和 quick/full/progressive
      → 单GPU顺序生成 → 快速版可玩 → 完整版（如选择）切换
      → 有边界地探索 → 导出离线场景包
```

## 八类模板与四个引擎

- 自然风景：地形旅程
- 室内空间、街道城市：空间漫游/高处下降
- 动物、人物、食物：主体微缩世界
- 建筑立面、艺术/旧照片：分层飞行/画布
- 无法准确分类的正常照片：通用分层实验模式，不硬性拒绝

## 智能体步骤

1. Moondream 2B 在本地判断类别、主体和透视线索。
2. 推荐场景模板、兼容模板、移动边界和风险说明。
3. 调用 MoGe 深度/几何生成器和 GLB 检查器。
4. 处理模型缺失、显存不足、数据缺失和质量不足；必要时进入明确的本地规则兜底。
5. 交付 manifest、GLB 和离线场景包。

## 状态机

`ANALYZING → PLANNED → QUICK_GENERATING → QUICK_READY → FULL_GENERATING → FULL_READY`

异常状态：`FAILED`、`EXPIRED`。

## 评分对应

| 赛事关注点 | 项目证据 |
| --- | --- |
| 任务理解与自主规划 | 本地视觉模型从照片选择模板并解释理由 |
| 工具调用与环境交互 | Moondream 2B、MoGe、GLB 检查和单 GPU 队列 |
| 结果交付与可验收性 | 可操作场景、manifest、GLB/离线包下载、测试记录 |
| 真实场景价值 | 普通创作者无需 3D 建模即可探索自己的照片 |

## 诚实边界

模板映射和基础查看器已经接通；四套引擎的几何差异、完全自包含离线 HTML 和逐类视觉质量仍需样片验收。
