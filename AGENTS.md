# Project instructions

## Scope

This repository is the student prototype for “走进照片”. Keep the first release focused on one uploaded horizontal corridor or room photograph becoming a bounded, explorable browser scene.

## Working rules

- Preserve user changes; inspect `git status` before editing.
- Do not add deferred features (phone, gestures, audio, multi-photo, movie scenes) to v1.
- Do not claim real 3D reconstruction. Clearly label AI-estimated unseen areas.
- Keep `DEEPSEEK_API_KEY` server-side and out of Git.
- Keep generated artifacts and private photos out of Git.
- Prefer small, reviewable commits and meaningful verification.

## Validation language

Distinguish `mock/demo` behavior from real model-backed behavior in code, UI, and documentation.
